# 🌍 ExploraDestinos — PWA

O **ExploraDestinos** é uma aplicação web progressiva (Progressive Web App - PWA) desenvolvida para consulta e visualização de destinos turísticos. O projeto combina recursos de acessibilidade e desempenho web, oferecendo navegação fluida em dispositivos móveis e desktops.

---

### ✨ Funcionalidades

- 📱 **Progressive Web App (PWA):** Instalação nativa em dispositivos móveis e desktops, com suporte a funcionamento offline via Service Worker.
- 📍 **Recurso de Hardware (GPS):** Acesso à geolocalização do dispositivo via `navigator.geolocation` para captura de coordenadas atuais (latitude e longitude).
- 🌓 **Tema Claro e Escuro (Light/Dark Mode):** Alternância dinâmica de cores otimizada para conforto visual.
- 🔍 **Filtro de Busca em Tempo Real:** Filtragem dinâmica de destinos na lista à medida que o usuário digita.
- 📐 **Design Responsivo:** Interface adaptável feita com CSS Grid e Flexbox para excelente visualização em smartphones, tablets e desktops.

---

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e inclusão de meta tags PWA.
- **CSS3:** Estilização responsiva, suporte a variáveis CSS para temas e layout adaptável.
- **JavaScript (Vanilla):** Manipulação da DOM, consumo de API de hardware (Geolocalização) e registro do Service Worker.
- **Service Worker & Web App Manifest:** Gerenciamento de cache offline e suporte à instalação do app.
